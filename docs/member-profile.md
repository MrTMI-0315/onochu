# Member Profile

## Goal

특정 멤버의 음악 취향과 추천곡을 한 화면에서 이해하고, 바로 대화를 시작할 실마리를 찾게 한다.

## Route

- `/members/[id]`

## Must Have

- 닉네임
- 한 줄 소개
- 선호 장르
- 주 사용 플랫폼
- 플레이리스트 링크 버튼
- 추천으로 답장하러 가는 CTA
- conversation starter 요약
- reaction / save aggregate
- 해당 멤버 추천곡 리스트

## Recommendation Section

- 곡명
- 아티스트명
- 플랫폼
- 코멘트
- 무드 태그
- 외부 링크 버튼
- 프로필에서 이어지는 사람 탐색 문맥

## States

- 정상 상세 상태
- 추천곡 없음 상태
- 잘못된 멤버 ID 상태

## Notes

- 프로필 정보와 추천곡 리스트의 시각적 구분이 분명해야 한다.
- 외부 링크 이동은 안전한 새 탭 처리 기준을 후속 구현 시 정의한다.
- 프로필 상단만 봐도 왜 이 사람을 눌러봤는지 이해할 수 있어야 한다.
- 최근 추천 중 어디서 대화를 시작하면 좋은지 한 줄로 제안해야 한다.
