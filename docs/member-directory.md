# Member Directory

## Goal

사용자가 다른 동아리원의 음악 취향을 빠르게 탐색하고 관심 있는 프로필 상세로 이동할 수 있게 한다.

## Route

- `/members`

## Must Have

- 프로필 카드 리스트
- 닉네임 검색
- 장르 태그 필터
- 플랫폼 필터
- 카드 클릭 이동

## Card Fields

- 닉네임
- 한 줄 소개
- 선호 장르 태그
- 주 사용 플랫폼
- 대표 플레이리스트 링크 또는 진입 CTA

## States

- 기본 목록 상태
- 검색 결과 없음 상태
- 필터 적용 상태

## Notes

- 필터 조합 상태가 UI에서 명확히 보여야 한다.
- 모바일 화면에서 카드 스캔이 빨라야 한다.
