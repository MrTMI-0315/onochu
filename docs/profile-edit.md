# Profile Edit

## Goal

사용자가 낮은 입력 부담으로 자신의 음악 취향 프로필을 생성하거나 수정할 수 있게 한다.

## Route

- `/profile/edit`

## Must Have

- 닉네임 입력
- 한 줄 소개 입력
- 선호 장르 태그 입력 또는 선택
- 주 사용 플랫폼 선택
- 플레이리스트 링크 1개 이상 입력
- 저장 성공/실패 피드백

## Validation

- 닉네임 필수
- 주 사용 플랫폼 필수
- 플레이리스트 링크 최소 1개 필수
- URL 형식 검증 필요

## States

- 생성 상태
- 수정 상태
- 저장 중 상태
- 저장 성공 상태
- 저장 실패 상태

## Notes

- 초기 MVP에서는 mock/local state 저장을 허용한다.
- 입력 필드는 짧고 명확해야 한다.
- 사용자는 상단만 보고도 “닉네임, 플랫폼, 링크 하나면 시작 가능하다”는 점을 이해할 수 있어야 한다.
